# Delegate Vote Contract

A governance contract that enables participants to delegate their voting
power to another address while retaining ownership of their tokens or
membership rights.

## Key Functions
- `delegate` — Assign voting power to a delegate
- `undelegate` — Revoke an active delegation
- `cast-vote` — Submit a vote using delegated authority
- `get-delegate` — View current delegate for an address
- `voting-power` — Calculate effective voting weight

Designed for DAOs seeking scalable governance with flexible participation.
